## 2. Кошторис і два резерви

Відсоток Contingency (5%) порахований від суми прямих витрат. Я обрала саме 5%, спираючись на наш реєстр ризиків: найбільш імовірні технічні ризики (як-от відсутність API розкладу, R-02) та проблеми з ПД (R-07) оцінюються в додаткові 86 годин роботи команди, що за нашою середньою ставкою складає приблизно 41 000 грн. Це покриває можливі затримки без перевитрат.

| Поле | Значення |
| --- | --- |
| Прямі витрати, грн | 821800 |
| Contingency, відсотків | 5 |
| Contingency, грн | 41090 |
| Baseline, грн | 862890 |
| Management reserve, грн | 43144 |
| Разом із резервом спонсора, грн | 906034 |

Management reserve відрізняється від Contingency тим, що він призначений для "невідомих невідомих" (ризиків поза реєстром), не входить у фіксований Baseline і розпоряджається ним виключно спонсор. Наприклад, якщо академія раптово змінить формат розкладу і нам доведеться переписувати парсер (подія поза реєстром) — це Management Reserve. А якщо розробники запізняться через складну архітектуру (ризик R-01 з реєстру) — це покривається з Contingency.
