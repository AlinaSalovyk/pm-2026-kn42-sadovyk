## 2. Як рахувалася симуляція

| Поле | Значення |
| --- | --- |
| Інструмент | власний скрипт Python |
| Прогонів | 10000 |
| Що тягнеться випадково | випадкове значення velocity з еталонного навчального масиву (пізніше — з моїх спринтів) |
| Як рахується дата прогнозу | для сценарію «весь перший реліз» кінець спринта 1 (2026-10-23) плюс (P − 1) × 14 днів, для сценарію залишку кінець останнього спринта плюс P × 14 днів |

Для перевірки методу Монте-Карло на навчальних даних курсу (обсяг 220 SP) використано цей скрипт:

```python
import math
import random

def run_monte_carlo(velocity_history, total_points=220, runs=10000):
    if not velocity_history:
        return None
    
    results = []
    for _ in range(runs):
        points_left = total_points
        sprints_needed = 0
        while points_left > 0:
            points_left -= random.choice(velocity_history)
            sprints_needed += 1
        results.append(sprints_needed)
    
    results.sort()
    p50 = results[math.ceil(0.50 * runs) - 1]
    p85 = results[math.ceil(0.85 * runs) - 1]
    
    return p50, p85

test_cases = {
    "Усі 12 спринтів": [21, 17, 26, 14, 23, 6, 28, 12, 22, 25, 18, 9],
    "Спринти 1 і 2": [21, 17],
    "Спринти 5 і 6": [23, 6],
}

for name, history in test_cases.items():
    p50, p85 = run_monte_carlo(history)
    print(f"{name}: P50 = {p50}, P85 = {p85}, Ширина = {p85 - p50}")
```
